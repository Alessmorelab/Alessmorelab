## 👋 About Me

- 🗺️ 做旅行助手时，我最关心的是：用户改了某一天的计划，地图上的路线能不能跟着更新？
- 🔎 做图数据应用时，我想让人能从一个风险分数，一路查到支撑它的原始交易。
- 🧪 我喜欢找那些差一点就会漏掉的情况，比如搜索词里的下划线，或者跨年那一周的图表。

## 📌 Featured Projects

### 🧭 [远行 Roam](https://github.com/Alessmorelab/Travelagent)

在微信里和助手聊出一份行程，打开按天整理的地点地图，再单独调整某一天。想看一次对话怎样从小程序走到地图工具，可以从[架构说明](https://github.com/Alessmorelab/Travelagent/blob/HEAD/docs/architecture.md)读起。

### 🕸️ [反诈资金图谱平台](https://github.com/Alessmorelab/Fraud-graph-platform)

从一个账户出发，查看一段时间内资金流向了哪里。工作台把批量风险评分、关联账户和带原始交易 ID 的证据放在一起，方便逐笔核对。
